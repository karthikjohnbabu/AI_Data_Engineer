# No agent attribution in git or code comments

- Never put the product/agent name (case-insensitive `cursor`) in commit messages, trailers, PR bodies, or code comments.
- Do not add `Co-authored-by` trailers that name the agent/product.
- Do not use `--trailer` for agent attribution when creating commits.
- Commit messages and comments must be professional project text only (what/why of the change).
