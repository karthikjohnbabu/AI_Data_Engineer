Is a single-window extract possible?

Yes — Glue can do it. One sql-server-extraction for the full pre-cutoff window (~42.7M / ~2.7 GB) fits the job capacity (G.2X×10, 48h timeout). Then arrange → Iceberg → one dim initial-load MERGE → BAU CDC path from player_balances keeps ≥ cutoff.

No Glue interactive session / notebook / ad-hoc Redshift COPY for prod gold — those skip the platform path, watermarks, and audit trail. Use them only for count dry-runs.

Caveats of the single-window extract (read before picking this)
